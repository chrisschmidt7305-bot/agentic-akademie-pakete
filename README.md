# Wissenspakete der Agentic-Coding-Akademie

Signierte Inhaltspakete (Ed25519) für die Android-App. Die App lädt `index.json` nur auf Knopfdruck, wenn die Online-Funktionen eingeschaltet sind, und prüft jedes Paket wie einen Datei-Import.

Der Index ist unsigniert – er kann höchstens verschweigen oder ein Paket anbieten, das die Prüfung nicht besteht.
